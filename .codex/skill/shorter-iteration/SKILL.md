# Итерации Shorter

Развивай продукт итерациями: MVP → спринты развития → следующий этап (Next Stage).

MVP — первая минимальная работающая версия. Спринт — ограниченный набор задач с конкретным результатом. Next Stage — переход к следующему этапу продукта после оценки результата.

Перед реализацией итерации определи цель, границы и проверяемые критерии готовности. Не добавляй функции за пределами выбранной задачи без необходимости.

При изменении требований читай и обновляй `docs/product.md`: актуальные требования, пользовательские сценарии, границы MVP и цели этапов. Пути отсчитываются от корня репозитория.

По завершении итерации зафиксируй результат, выполненные проверки, оставшиеся ограничения и следующие приоритеты. Не начинай новый этап автоматически без согласованной цели.
