# Документация Shorter

Все пути отсчитываются от корня репозитория. Читай документы по необходимости задачи:

- `docs/product.md` — актуальные требования, пользовательские сценарии, границы MVP и цели этапов; при изменении требований.
- `docs/architecture.md` — актуальное устройство системы и принятые технические решения с обоснованием и ссылками на логи; при технических решениях.
- `docs/logs/` — история задач и решений; для изучения причин решений.

При начале содержательной задачи или связанной группы изменений создай `docs/logs/NNNN-short-topic.md`, выбрав следующий свободный номер. Обновляй запись по мере работы. Для небольшой правки достаточно краткой записи; отдельный лог для каждой команды или файла не нужен.

Даты в документации и логах не указывай. Лог содержит задачу, предложенное решение, статус решения, обоснование, результат и проверки. При существенном выборе укажи рассмотренные альтернативы. Различай предложенное, принятое, реализованное и проверенное. Предложение агента само по себе не является согласованным требованием.

При пересмотре решения сохраняй историю: отмечай замену и ссылайся на новое решение. Не переписывай прошлое так, будто первоначального решения не было.

Обновляй документацию в рамках той же задачи, которая меняет соответствующее поведение или устройство проекта. Не дублируй полный текст логов в других документах.

В `VERSIONS.md` кратко фиксируй основные завершённые изменения по версиям; подробности и причины оставляй в логах. Каждая запись по возможности ссылается на соответствующий лог.

До выпуска помещай изменения в `Unreleased`. Номер выпуска фиксируй только при фактическом выпуске; не выдавай планы за выполненную работу.

Используй Conventional Commits: `feat`, `fix`, `refactor`, `perf`, `docs`, `test`, `build`, `ci`, `chore`; при необходимости добавляй область, например `feat(links)`. Несовместимые изменения отмечай `!` и поясняй последствия. Эти обозначения применяй к сводке и сообщениям коммитов, когда коммиты входят в задачу.

Команды установки, запуска и проверок добавляй в `README.md`, когда будет выбран стек и появится приложение.
