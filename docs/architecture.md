# Архитектура

Backend использует Go и стандартную библиотеку: `net/http` для HTTP, `log/slog` для логов. Точка входа — `cmd/shorter`. Сейчас сервер предоставляет только `GET /healthz`; доменная логика ещё не реализована. По мере её появления ядро отделяется от HTTP и хранения по Ports & Adapters.

Принятое хранилище — PostgreSQL. Оно заменяет первоначальный ориентир in-memory для MVP. Приложение пока не устанавливает соединение с БД; схема и миграции не реализованы.

Dockerfile собирает статический Go-бинарник в отдельном этапе и запускает его в Alpine от непривилегированного пользователя. Compose содержит только backend и PostgreSQL 17. Для базы используется именованный том; backend ожидает её готовности через `pg_isready`. Порт базы на хост не публикуется.

Решение и границы: [базовая инфраструктура](logs/0002-docker-infrastructure.md).
