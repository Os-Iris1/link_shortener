# Продукт

Shorter — сервис сокращения ссылок на Go с PostgreSQL и интерфейсом на JavaScript и React.

## Текущая задача: минимальный frontend и структура

По запросу пользователя серверный код выделен в `backend`, клиентский — в `frontend`. Миграции остаются в корневом `migrate`.

Пользователь вводит полный HTTP(S) URL, отправляет форму, получает короткую ссылку, копирует её или открывает. Интерфейс показывает состояние запроса и ошибки; повторная отправка во время запроса заблокирована. При недоступном буфере обмена ссылка выделяется для ручного копирования. Страница адаптируется к мобильной ширине.

Критерии готовности: сборка React на JavaScript, создание ссылки через существующий API, открытие результата, обработка ошибок, совместный запуск через Compose, успешные проверки Go после переноса и обновлённые команды разработки. История ссылок, учётные записи и управление ссылками не входят в задачу.

Статус реализации и проверки: [лог backend/frontend](logs/0009-backend-frontend.md). Требуется пользовательский code review перед интеграцией в `dev`.

## Завершённая задача: инфраструктура

Цель — подготовить запуск Go backend на `net/http` и PostgreSQL через Docker Compose.

Границы: Dockerfile, два сервиса Compose, постоянное хранение данных PostgreSQL и минимальный HTTP-сервер для проверки запуска. API ссылок, подключение backend к БД, схема и миграции в эту задачу не входят.

Критерии готовности: сборка backend, ответ `ok` на `GET /healthz`, корректная конфигурация Compose с ожиданием готовности базы и документированные команды запуска.

Статус реализации и проверки: [лог инфраструктуры](logs/0002-docker-infrastructure.md).

## Завершённая задача MVP: создание короткой ссылки

Пользователь отправляет `POST /api/links` с `Content-Type: application/json` и телом `{"url":"https://example.com/path"}`. После записи в PostgreSQL сервис возвращает 201 и `{"short_url":"http://localhost:8080/<код>"}`. Публичный адрес берётся из `BASE_URL`, а не из заголовков запроса.

Допускаются абсолютные HTTP(S) URL без учётных данных длиной до 8192 байт. Повторное сокращение того же URL создаёт новую запись; дедупликации нет. Коды случайные, уникальность обеспечивает PostgreSQL; при коллизии сервис повторяет генерацию до пяти попыток.

Некорректные JSON и URL дают 400, неподдерживаемый Content-Type — 415, тело больше 64 KiB — 413, ошибка сохранения — 500 без внутренних подробностей. При ошибке сохранения успешный ответ не возвращается.

Критерии готовности: успешный ответ соответствует сохранённой записи; ошибки запросов не записываются; коллизии не перезаписывают данные; сервис и репозиторий проверены Table-Driven тестами с gomock и pgxmock; test/race/vet проходят. Схема управляется версионированными SQL-миграциями в `migrate`, применяемыми до старта backend.

Границы: переход по короткой ссылке, пользовательские коды, срок жизни и управление ссылками не реализуются в этой задаче. Возвращаемый адрес пока не выполняет редирект.

Результат и проверки: [лог создания ссылки](logs/0005-create-short-link.md).

Задача принята пользователем после исправления работы со схемой БД и успешной финальной проверки. Проверки и разрешение на интеграцию в dev: [финальная приёмка](logs/0007-versioned-sql-migrations.md#финальная-проверка-и-приёмка).

## Завершённая задача: переход по короткой ссылке

Пользователь подтвердил вариант `GET /<код>` с редиректом `302 Found` на сохранённый исходный URL через `Location`. Query и fragment исходного URL сохраняются. Поддерживается `HEAD` без тела ответа.

Неверный формат кода — 400; корректный, но неизвестный код — 404; ошибка хранилища или истечение таймаута операции — 500 без внутренних подробностей. Формат кода соответствует генератору: 12 регистрозависимых символов base64url. Другие методы — 405 с `Allow`; пустой путь и лишние сегменты — 404.

Критерии готовности: чтение созданной ссылки из PostgreSQL, тесты сервиса/репозитория/HTTP, успешные test/race/vet и проверка запущенного приложения. Пользователь одобрил результат и разрешил слияние; последний запуск и проверки перед интеграцией в `dev` успешны. Статус и результаты: [лог задачи](logs/0008-resolve-short-link.md#финальная-проверка-и-приёмка).
