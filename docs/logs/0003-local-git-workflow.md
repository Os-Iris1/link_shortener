# Локальная работа с Git

- Задача: добавить навык работы с ветками и коммитами.
- Решение: закрепить разрешение на локальные Git-операции, запрет отправки на удалённый сервер, Gitflow с ветками `dev`, `release`, `stage` и Conventional Commits.
- Статус: правила приняты пользователем; навык реализован и структурно проверен.
- Обоснование: запрет внешней отправки должен быть виден в `AGENTS.md` до загрузки навыка; подробности локального процесса вынесены в `shorter-git`.
- Границы: создание навыка и обновление маршрутизации; коммиты, создание веток и слияния в рамках этой задачи не выполняются. Точное направление продвижения между `release` и `stage` пользователем пока не определено.
- Критерии готовности: навык имеет метаданные и ссылку из `AGENTS.md`, явно запрещает отправку и описывает локальные коммиты и ветки.
- Результат: создан `.codex/skill/shorter-git/SKILL.md`, добавлены ссылка и общий запрет отправки в `AGENTS.md`, обновлён `VERSIONS.md`.
- Проверки: `quick_validate.py` для `shorter-git` прошёл успешно; существование файла ссылки подтверждено; `git diff --check` выполнен без ошибок. Ветки и коммиты не изменялись, внешняя отправка не выполнялась.
- Ограничение: порядок продвижения между `release` и `stage` требует определения при соответствующей задаче; автоматическое обнаружение навыка клиентом не проверялось, предусмотрена прямая ссылка.
