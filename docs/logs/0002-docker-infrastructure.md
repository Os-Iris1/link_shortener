# Базовая инфраструктура

- Задача: подготовить Dockerfile и `docker-compose.yaml` только для Go backend и PostgreSQL.
- Цель и границы: воспроизводимая сборка и запуск двух контейнеров, без API сокращения ссылок и схемы БД.
- Критерии готовности: backend собирается, HTTP отвечает на `/healthz`, Compose описывает PostgreSQL с постоянным томом и проверкой готовности; команды документированы.
- Решение: многоэтапная сборка Go, минимальный HTTP-сервер, PostgreSQL 17, именованный том и ожидание `service_healthy`.
- Статус: стек принят пользователем; инфраструктура реализована и проверена.
- Обоснование: минимальный сервер позволяет собрать и запустить backend уже в этой итерации; PostgreSQL заменяет прежний ориентир in-memory из `0001-extract-project-skills.md` и `shorter-go` по прямому решению пользователя. Исходный лог сохраняется.
- Альтернативы: Dockerfile без приложения не даёт запускаемого backend; in-memory отклонено новым решением пользователя.
- Результат: добавлены Dockerfile, Compose, минимальный сервер с `/healthz`, Go-модуль, исключения Git и Docker, README, продуктовые и архитектурные документы; обновлены навык Go и сводка версий.
- Проверки: `go test ./... -cover`, `go vet ./...`, `go test -race ./...` выполнены без ошибок; тестовых файлов пока нет. Локальная HTTP-проверка дала `200 ok`. `docker compose -f docker-compose.yaml config --quiet` и `build backend` успешны. Совместный запуск через `up -d --wait --wait-timeout 120` успешен: PostgreSQL healthy, HTTP из контейнера вернул `200 ok`, `SELECT 1` через `psql` вернул 1. После проверки выполнен `down`, том сохранён. Обновлённый навык прошёл структурную валидацию.
- Ограничения: приложение пока не подключается к PostgreSQL; `/healthz` проверяет только HTTP. Схема, миграции, бизнес-логика и API ссылок отсутствуют. Теги образов фиксируют линии версий, а не digest. Параметры доступа предназначены для локальной разработки.
- Следующий приоритет: согласовать минимальные сценарии API и модель хранения перед следующей задачей; автоматически следующий этап не начинается.
